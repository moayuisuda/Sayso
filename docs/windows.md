# Windows 宿主

Windows 客户端使用 WinUI 3。配色、圆角、顶部页签、卡片列宽和候选框分组沿用 macOS 的视觉规范。
系统浅色、深色主题分别定义资源，设置窗口使用 Mica，候选框使用 Acrylic。
候选框中的单条状态提示使用紧凑单行布局，识别和翻译结果按内容展开。浮层共用块渲染器与主题资源，
不再嵌套卡片或固定底栏；设置与关闭使用小图标按钮，错误色仅用于状态图标，窗口始终不抢输入焦点。
录音时显示真实麦克风 RMS 音量条、持续计时和实时识别文字，录音结束后切换为识别等待提示。
音量由平台采集层提供，界面按需采样；录音、识别及结果阶段继续由 Core 的会话事件驱动。
千问使用 `qwen-audio-3.1-asr-flash-message`，开启中间结果、关闭润色，并将目标语言与本地语言作为
`language_hints`。设置页不提供手填识别上下文，不再使用旧的 `corpus.text`。
语言提示只影响最终结果，中间文字可能修订。核心按句子 ID 更新转写，等任务正常结束后才提交翻译。

## 核心边界

`sayso-core` 是设置、扩展、存储、识别、翻译与会话的唯一实现。Swift 宿主使用已有 UniFFI 绑定；
Windows 宿主通过 `sayso-windows-bridge` 的窄 C ABI 调用相同的 `Core`，不复制业务规则。

- `sayso_create` 创建唯一实例，传入平台回调与对应内存释放函数。
- `sayso_call` 执行请求并返回 UTF-8 JSON，返回内存由 `sayso_free` 释放。
- `sayso_audio` 接收 16 kHz、单声道、16 位小端 PCM。
- `sayso_complete` 完成异步选区或文字写入调用；会话取消时取消信号会传回 Windows。
- `sayso_destroy` 停止核心并释放实例。宿主先停止热键和音频，再销毁核心。

同步回调只处理系统能力或排队 UI 通知。选区与写入操作在 UI STA 线程异步执行，Rust 使用 oneshot 等待，
不会同步阻塞核心工作线程。核心通知回调不允许同步重入 `Core`。

`CoreClient` 串行执行普通调用，在工作线程进入原生边界；设置修改在同一事务内从核心读取最新值再更新，
避免连续修改多个控件时覆盖旧快照。UI 持有的设置仅用于渲染。

路由编辑通过 `Core::bind_command` 与 `Core::set_route_input` 提交意图，Swift 的 UniFFI 绑定与 Windows 桥接共用这些接口。
改绑继承、首次绑定默认值、共享路由及解绑清理由 `settings` 模块统一实现，Core 在设置锁内完成修改与落盘，释放锁后通知宿主。
宿主只采集按键、展示路由并传入平台键码，不再增删路由或命令绑定数组。

## 系统适配

- **录音**：NAudio.Wasapi 捕获默认输入设备，转换声道与采样率后交给核心。停止操作等待尾部音频交付完成。
- **热键**：低级键盘钩子过滤注入事件，按下与松开事件交给同一个核心会话；默认右 Ctrl，T 为选区路由。
- **候选框关闭**：结果框按 Enter、点击框外或切换前台窗口时关闭，Enter 与鼠标点击仍传给目标应用。
  宿主只在展示结果时监听框外事件，并携带面板 ID 调用 `Core::dismiss_surface`；核心忽略旧面板事件，录音与识别阶段不受影响。
- **剪贴板**：复制前保留所有可读取格式；通过剪贴板序列号判断是否可以恢复，避免覆盖用户随后复制的新内容。
- **文字写入**：验证原始目标窗口仍能激活后发送 Ctrl+V；不能写入时结果留在剪贴板，由核心展示投递结果。
- **朗读**：使用 Windows SAPI 与已安装的语言语音。缺少语音时，平台返回 `PlatformError`，核心将原因显示在候选框中并保留译文；自动朗读和按钮朗读共用这条链路，成功重试后清除提示。可从「通用 → 朗读 → 管理朗读语音」进入 Windows 语音设置安装对应语言，安装后重启应用。
- **密钥**：使用 Windows Credential Manager，测试进程使用独立命名空间。
- **常驻**：托盘负责设置与退出；同用户命名管道把二次启动和扩展包路径交给已有实例。

## 验证

```powershell
./scripts/build-windows.ps1 -Test
```

Rust 测试验证会话、扩展运行时、协议、存储，以及跨 ABI 的设置持久化与扩展包安装/导出。
`Sayso.exe --smoke-test` 在真实 WinUI 进程中检查页面创建、凭据管理器、Unicode 剪贴板、WASAPI 与可取消回调。
测试数据位于系统临时目录，正式用户数据位于 `%LOCALAPPDATA%\Sayso`。

云端测试必须使用真实服务和有效配置；本地检查不代表云端语音识别与翻译已通过。

`core/sayso-core/examples/test_qwen.rs` 可回放 16 kHz 单声道 Int16 PCM 文件，使用正式的识别管线调用真实服务。
参数为音频路径、目标语言代码和本地语言代码；API Key 从标准输入读取，不放入命令参数或输出。

`core/sayso-core/examples/test_dictation.rs` 用正式内置插件和 LLM 客户端回放文本：参数为设置文件和用例 JSON 路径，密钥从标准输入读取。
用例格式为 `[{"transcript":"I have a 苹果.","languages":{"target":"en","native":"zh"}}]`。回放同时执行正式生词本插件，输出整句译文、高亮片段、生词块与失败提示，不写入用户当前应用或生词本，也不播放语音。

用例可指定 `contains`、`excludes` 字符串数组，对实际整句输出做断言。`core/sayso-core/tests/fixtures/dictation-phonetic.json` 覆盖 8 种目标语言的首轮读音误识别，以及正常母语、姓名、数量词的反例；使用该文件回放可验证目标语还原规则。
